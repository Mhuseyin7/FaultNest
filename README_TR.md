# FaultNest

## Yakala. İzole et. Yeniden oynat.

FaultNest, zor yeniden üretilen yazılım hatalarını yerel, taşınabilir ve sanitize edilmiş hata paketlerine dönüştüren bir Rust aracıdır. Otomatik veri yüklemez; `.env` dosyalarını veya tüm depoyu kopyalamaz.

Kullanım ve teknik ayrıntılar için İngilizce [README](README.md) belgesine bakın.
