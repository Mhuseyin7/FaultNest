# Threat model

Bundles are untrusted input. The verifier rejects path traversal, absolute paths, oversized entries, excessive total size, corrupted ZIP data, absent manifest/checksums, and BLAKE3 mismatches. Inspection never executes archive content. Replay requires explicit `--yes`, uses executable/argv API, avoids shell concatenation, enforces a deadline, and writes a marker before `down` will remove a workspace. Capture paths reject workspace escapes. Docker replay has no socket or privilege, drops capabilities, uses `no-new-privileges`, resource limits and restricted networking. Database capture accepts only reviewed JSON fixtures with explicit table and row allowlists; it never connects to production databases.
